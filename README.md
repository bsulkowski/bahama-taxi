# Bahama Taxi

A card-based board game for 2-4 players.

*Author: Bartosz Sułkowski*

## Available language versions

- [English](README.md)
- [Polish](README_pl.md)

## Overview

Bahama Taxi is a card-based board game for 2–4 players. Players take the roles of taxi drivers competing to earn the highest income by picking up and delivering passengers across a city board. The board has 52 areas mapped to a standard card deck — suits define city districts, while the central Downtown uses face card ranks. Each turn a player moves their taxi one area and can pick up or drop off passengers. Citizens are represented by card pairs drawn randomly from the deck, and fares are based on the shortest route between pickup and destination. The game ends when no more citizens are waiting, and the player with the most income wins.

## Equipment

- printed board
- standard 52-card deck
- distinguishable tokens (one for each player)
- a paper and a pencil
